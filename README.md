# Learn Lock — 边学边玩的 [SillyTavern](https://github.com/SillyTavern/SillyTavern) 防沉迷插件

> 锁住 AI 消息正文，答对词汇翻译题才能逐段解锁阅读。阅读过程中可点击高亮词汇查看释义、收藏生词、复习错题。

## ✨ 功能一览

- **学习解锁**：AI 回复的消息被分段锁定，回答词汇翻译题后逐段解锁
- **智能出题**：从消息文本上下文抽词出题，也支持错题本优先复习
- **双向翻译**：中译英 / 英译中可自由开关
- **六级难度**：入门 A1 → 挑战 C1，自动筛选适合你的词汇
- **同义词判题**：宽松模式接受同义词作答，严格模式只认标准答案
- **词汇高亮**：正文中的英文和中文词库词汇自动高亮，点击弹出词卡
- **离线词卡**：集成 ECDICT 离线词典，音标、释义、词性、考试标签一应俱全
- **TTS 发音**：无在线音频时自动使用浏览器内置 TTS 朗读单词
- **错题本**：基于 SM-2 间隔重复算法，自动安排复习时间
- **单词收藏**：点击词卡星标即可收藏，随时在学习面板中查看
- **自定义正则**：过滤 AI 消息中的 OOC / 元数据 / 结构标签，不影响正文
- **流式兼容**：支持流式生成，边生成边锁定边答题
- **错题词卡**：错题本里只需点击条目即可展开对应单词卡，复盘更高效

## 📦 安装

### 方法一：通过 SillyTavern 扩展安装器

1. 打开 SillyTavern → 扩展 → 安装扩展
2. 输入仓库地址：`https://github.com/Gu-gu-gu-gu-gu/LearnLock`
3. 点击安装

### 方法二：手动安装

```bash
cd SillyTavern/data/default-user/extensions
git clone https://github.com/Gu-gu-gu-gu-gu/LearnLock.git
```

刷新 SillyTavern 页面即可。

## 📖 使用说明

1. 在扩展设置中勾选 **启用学习解锁**
2. 与 AI 对话，收到回复后消息正文会被锁定
3. 在消息下方的答题面板中输入翻译答案并提交
4. 答对后解锁对应段数的正文，继续答题直到全部解锁
5. 解锁后的正文中，词汇高亮可点击查看详情
6. 点击扩展菜单中的 **学习面板** 可管理错题本、收藏和设置

## ⚙️ 配置项

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| 词汇难度 | A1 入门 ~ C1 高级 | 中级 (A1~B1) |
| 判题模式 | 宽松（同义词判对）/ 严格 | 宽松 |
| 题型 | 中译英 / 英译中 | 两者都开 |
| 每题解锁段数 | 答对一题解锁多少段 | 1 |
| 错题优先概率 | 从错题本出题的概率 | 30% |
| 每条消息词卡上限 | 限制每条 AI 回复中可显示的高亮词卡数量（0 为无限制） | 40 |
| 错误几次后提示 | 连错几次显示首字母提示 | 2 |
| 忽略正则 | 过滤 AI 输出中的元数据 | 空 |
